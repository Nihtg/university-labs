## ⏱ Золотой стандарт 5-минутного устного ответа на зачете

Каждый ответ в конспектах спроектирован по таймингу для уверенного выступления перед доцентом Курбатовым В. А.:

| Тайм-код | Смысловой блок | Что говорить экзаменатору |
| :---: | :--- | :--- |
| **00:00–01:00** | **Определение, авторы и базис** | Точная формулировка термина, основоположники (Тэнсли, Сукачёв, Вернадский, Либих, Шелфорд, Израэль и др.), классификационное место явления. |
| **01:00–03:00** | **Теория, формулы и химизм** | Математические законы (Линдеман, Лотка-Вольтерра, Ферхюльст), формулы балансов ($NPP = GPP - R_a$), химические уравнения реакций (фотосинтез, цикл озона Чепмена, нитрификация, образование кислот, сульфатредукция), классификации аппаратов и параметров. |
| **03:00–04:00** | **Биосферные последствия и IT-контекст** | Примеры реальных кризисов (Минамата, Чернобыль, эвтрофикация, остров тепла мегаполиса), воздействие на IT-инфраструктуру (серверные, дата-центры, охлаждение, e-waste, перегрузка сетей, электромагнитный смог). |
| **04:00–05:00** | **Инженерные решения, ГОСТ/СанПиН и вывод** | Нормативная база РФ (СанПиН 1.2.3685-21, ФЗ № 7, ФЗ № 89, ФЗ № 96), санитарные нормативы (ПДК, ПДУ, ПДВ), инженерные очистные системы (скрубберы, электрофильтры, аэротенки), краткая итоговая шпаргалка. |
