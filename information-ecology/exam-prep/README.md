# 🎯 Подготовка к зачету и тестированию

## Разделы:
1. **Вопросы к зачету по информационной экологии**:
   - Вопросы по физическим факторам воздействия (освещенность, шум, электромагнитные излучения, ионизирующие излучения).
   - Вопросы по правовым и нормативно-техническим основам охраны труда и экологии в сфере IT и телекоммуникаций.
   - Экологическая безопасность телекоммуникационных систем и оборудования связи.

2. **Тестирование по курсу**:
   - Тренировочные тестовые вопросы.
   - Ответы и пояснения для успешной сдачи онлайн-теста.
