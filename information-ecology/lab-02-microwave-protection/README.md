# Лабораторная работа №2
## Тема: Защита от СВЧ излучения

### Цель работы
Изучение характеристик электромагнитных полей сверхвысоких частот (СВЧ), нормирования их воздействия на организм человека и методов расчета защитных экранов.

### Задачи
1. Определить плотность потока энергии (ППЭ) в рабочей зоне источника СВЧ-излучения.
2. Сравнить полученные значения с предельно допустимыми уровнями (ПДУ) по СанПиН.
3. Рассчитать требуемую эффективность экранирования и выбрать материал защитного экрана (сетка, фольга, перфорированный металлический лист).

### Структура папки
- `src/` — расчетные модули на Python (расчет ППЭ, затухания в экране, допустимого времени экспозиции).
- `docs/` — отчет по лабораторной работе в формате `.docx`.
