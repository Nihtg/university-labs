# Лабораторная работа №1
## Тема: Расчёт естественной освещённости в производственном помещении

### Цель работы
Получить практические навыки нормирования и инженерного расчёта естественного освещения производственных помещений (помещений вычислительных центров, рабочих мест операторов и инженеров IT).

### Задачи
1. Определить нормированное значение коэффициента естественной освещенности (КЕО) $e_N$ с учетом разряда зрительной работы и географического пояса светоклимата.
2. Рассчитать требуемую суммарную площадь световых проемов (окон) для обеспечения нормативной освещенности рабочего места.
3. Провести сопоставление фактического и расчетного значения КЕО.

### Структура папки
- `src/` — скрипт на Python для автоматизированного расчета КЕО, площади окон и проверки нормативных условий СП 52.13330 (СНиП 23-05-95).
- `docs/` — отчет по лабораторной работе в формате `.docx` по требованиям ГОСТ 7.32.
