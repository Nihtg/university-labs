## 🏛️ Регламент сдачи дифференцированного зачета
- **Формат:** Индивидуальный устный опрос в онлайн-режиме (видеосвязь с включенной камерой и микрофоном).
- **Билет / Вопросы:** Преподаватель задает **два вопроса** из утвержденного перечня (46 вопросов).
- **Время на подготовку:** **Не предоставляется** (ответ дается сразу после озвучивания вопроса).
- **Критерии оценивания:**
  - Оценка «автоматом» ставится **только отличникам** (при свободном владении понятийным аппаратом, первоисточниками и персоналиями).
  - «Автомата на тройку» не существует — зачет сдают все студенты.
  - Формальные рефераты, сгенерированные нейросетями, отвергаются преподавателем как профанация.
