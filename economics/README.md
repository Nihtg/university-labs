## 🎯 Основные темы
- [x] **Основы экономической теории и микроэкономики:** факторы производства, КПВ, рынок, спрос, предложение, рыночное равновесие, эластичность, типы конкуренции ([Лекция №1](./lectures/lecture-01.md)).
- [x] **Экономика предприятия:** предприятие, организационно-правовые формы, издержки (, VC, TC, AFC, AVC, ATC, MC$), выручка, экономическая/бухгалтерская прибыль, правила =MC$ и закрытия, решение расчетных задач 1–5 ([Практика №1](./practices/practice-01.md)).
- [ ] **Макроэкономические показатели:** ВВП, инфляция, безработица, фискальная и монетарная политика.
- [ ] **Экономика IT-предприятий:** оценка экономической эффективности программных проектов.
