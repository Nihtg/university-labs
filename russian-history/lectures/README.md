## 💡 Порядок работы с материалами
1. Изучите академический конспект в файле соответствующей лекции ([`lecture-01.md`](./lecture-01.md)).
2. При необходимости обратитесь к пошаговым таймкодам или полной стенограмме ([`transcripts/`](./transcripts/)) для сопоставления с видеозаписью занятия.
3. Используйте контрольные вопросы в конце каждого конспекта для подготовки к дифференцированному зачету.
